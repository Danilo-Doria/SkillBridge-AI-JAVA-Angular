# Audit Service

The **Audit Service** is a microservice responsible for tracking and logging domain events generated by the SkillBridge application, such as bookings and cancellations.

## Architecture

It is composed of two main applications:

1. **Backend (`audit-service/backend`)**: A Spring Boot application that acts as a Kafka Consumer. It listens to the `booking-events` topic and persists recent events in an in-memory repository. It also exposes a REST API to query these events and general statistics.
2. **Frontend (`audit-service/frontend`)**: An Angular 20 application that displays a dashboard for administrators, showing statistics (created/cancelled bookings) and a live list of the latest audit events.

## Components

### Backend API Endpoints

- `GET /api/audit/events`: Returns the list of latest recorded events.
- `GET /api/audit/stats`: Returns aggregated statistics of the events.

### Frontend Dashboard

- Uses Angular 20 Signals for reactive state management.
- Reaches the backend API either via proxy (`/api/`) or direct CORS request.

## How to Run

The audit service is integrated into the main `docker-compose.yml`. You can start it along with the rest of the infrastructure:

```bash
docker compose up -d audit-backend audit-frontend
```

Once running:
- The **Backend API** will be accessible at [http://localhost:8081](http://localhost:8081).
- The **Frontend Dashboard** will be accessible at [http://localhost:8090](http://localhost:8090).

## Kafka Integration

The service connects to the existing Kafka cluster via the `KAFKA_BOOTSTRAP_SERVERS` environment variable (`kafka:29092` inside Docker). It subscribes to the `booking-events` topic using the `audit-service-group` consumer group.
